# FastDeep Scanner

เครื่องมือคัดกรองและศึกษาหุ้น **1,458 ตัว** จาก 4 ตลาด — สหรัฐ · จีน · ฮ่องกง · ไทย
ทำงานบนเครื่องของคุณเอง ฟรี ไม่ต้องสมัครสมาชิก ข้อมูลและบันทึกทั้งหมดเป็นของคุณคนเดียว

> **ใช้เพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำการลงทุน**
> ตัวเลขทุกอย่างมาจากการคำนวณอัตโนมัติ ไม่ใช่สัญญาณซื้อขาย
> การลงทุนมีความเสี่ยง ผู้ลงทุนรับผิดชอบการตัดสินใจของตนเอง

## ⚠️ อ่านตรงนี้ก่อน

**หน้าเว็บ GitHub นี้ติดตั้งโปรแกรมให้ไม่ได้** — มันเป็นแค่ที่เก็บโค้ด
การกดเข้าไปดูไฟล์อย่าง `setup.bat` จะเห็นแค่ข้อความในไฟล์ ไม่ใช่การติดตั้ง

**ต้องดาวน์โหลดลงเครื่องก่อน แล้วรันบนเครื่องตัวเอง** ตามขั้นตอนด้านล่าง

## ติดตั้งใน 4 ขั้น

### 1. ติดตั้ง Python

โหลดจาก **https://www.python.org/downloads/** (ต้องเวอร์ชัน 3.11 ขึ้นไป)

> 🔴 **จุดที่พลาดกันมากที่สุด**
> ในหน้าจอแรกของตัวติดตั้ง ให้**ติ๊กช่อง `Add Python to PATH`** ที่อยู่ด้านล่างก่อน
> แล้วค่อยกด Install Now — ถ้าลืมติ๊ก โปรแกรมจะหา Python ไม่เจอ

### 2. ดาวน์โหลดโปรแกรม

กดปุ่มเขียว **`< > Code`** ที่อยู่มุมขวาบนของหน้านี้ → เลือก **Download ZIP**

หรือกดลิงก์นี้ได้เลย → **[ดาวน์โหลด ZIP](https://github.com/three-fastbull/FASTDEEPSCANNER/archive/refs/heads/main.zip)**

แตกไฟล์ไว้ที่ที่หาเจอง่าย เช่น `D:\FASTDEEP SCANNER`

> อย่าแตกไฟล์ไว้ใน Desktop หรือ Downloads ที่ซิงก์กับ OneDrive
> เพราะข้อมูลจะโตถึง 600 MB แล้ว OneDrive จะพยายามอัปโหลดตลอดเวลา

### 3. ดับเบิลคลิก `setup.bat`

ไฟล์นี้อยู่ในโฟลเดอร์ที่แตกไว้ มันจะทำให้เองทั้งหมด 5 ขั้น

| ขั้น | ทำอะไร | เวลา |
|---|---|---|
| 1 | หา Python บนเครื่อง | ทันที |
| 2 | ถามอีเมลของคุณ (ใช้แจ้ง SEC ตอนดึงงบ) | ทันที |
| 3 | ดึงราคาหุ้น 1,458 ตัว ย้อนหลัง 5 ปี | 2-5 นาที |
| 4 | ดึงงบการเงินจาก SEC EDGAR | ~15 นาที |
| 5 | ตรวจความพร้อมทั้งหมด | ทันที |

**รวมประมาณ 25 นาที** ระหว่างนี้เปิดค้างไว้ได้ ไม่ต้องเฝ้า

### 4. ดับเบิลคลิก `OPEN_FASTDEEP_SCANNER.bat`

เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:8765` เอง — นั่นคือเครื่องของคุณเอง

## เช็คว่าติดตั้งครบไหม

เปิด Command Prompt ในโฟลเดอร์โปรแกรม แล้วพิมพ์

```bash
python -m fastdeep_scanner doctor
```

จะบอกทุกอย่างว่าผ่านหรือขาด และถ้าขาดจะบอกคำสั่งแก้มาให้เลย

```
  [ ผ่าน ] Python                    เวอร์ชัน 3.12.10
  [ ผ่าน ] อีเมลติดต่อ SEC           you@example.com
  [ ผ่าน ] รายชื่อหุ้น               1,458 ตัว
  [ ผ่าน ] ข้อมูลธุรกิจภาษาไทย       523 บริษัท
  [ ผ่าน ] ราคาหุ้น                  135 MB, ล่าสุด 2026-09-04
  [ ผ่าน ] งบการเงิน                 1,460 บริษัท
```

## มีอะไรให้ใช้บ้าง

| แท็บ | ใช้ทำอะไร |
|---|---|
| **Scanner** | หาหุ้นที่รูปกราฟและพื้นฐานเข้าเกณฑ์พร้อมกัน |
| **คัดจากเมกะเทรนด์** | ดูหุ้นแยกตามอุตสาหกรรมและแนวโน้มระยะยาว |
| **Hall of Fame** | ดูว่าหุ้นที่ให้ผลตอบแทนดีที่สุด 10 ปีที่ผ่านมาหน้าตาเป็นยังไง |
| **ข้อมูลบริษัท** | อ่านว่าบริษัททำอะไร หาเงินยังไง คู่แข่งเป็นใคร |
| **งบการเงิน 5 ปี** | รายได้ กำไร กระแสเงินสด ย้อนหลัง แยกสกุลเงินชัดเจน |
| **VI Thesis** | ประเมินมูลค่าตามหลักการลงทุนแบบเน้นคุณค่า |
| **หลักฐานย้อนหลัง** | ดูว่ารูปแบบกราฟแต่ละแบบเคยได้ผลจริงแค่ไหน |
| **Paper Trade** | จดการซื้อขายสมมติไว้ฝึกมือ ยังไม่ต้องใช้เงินจริง |

**คะแนน A/A+ จะไม่ขึ้นเองอัตโนมัติ** ต้องให้คุณเข้าไปวิเคราะห์ธุรกิจและบันทึก Moat เองก่อน
นี่คือเจตนาของระบบ — เครื่องช่วยกรองให้ แต่การตัดสินใจสุดท้ายยังเป็นของคนเสมอ
