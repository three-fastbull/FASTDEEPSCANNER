# FastDeep Scanner — คู่มือติดตั้งสำหรับนักเรียน

เครื่องมือคัดกรองและศึกษาหุ้น 1,458 ตัวจาก 4 ตลาด (สหรัฐ · จีน · ฮ่องกง · ไทย)
ทำงานบนเครื่องของคุณเอง ข้อมูลและบันทึกทั้งหมดเป็นของคุณคนเดียว

> **ใช้เพื่อการศึกษาเท่านั้น ไม่ใช่คำแนะนำการลงทุน**
> ตัวเลขทุกอย่างมาจากการคำนวณอัตโนมัติ ไม่ใช่สัญญาณซื้อขาย
> ก่อนตัดสินใจจริงต้องตรวจสอบจากแหล่งทางการเสมอ การลงทุนมีความเสี่ยง

## สิ่งที่ต้องมีก่อน

| | |
|---|---|
| ระบบปฏิบัติการ | Windows 10 หรือ 11 |
| พื้นที่ว่าง | อย่างน้อย **1.5 GB** |
| อินเทอร์เน็ต | ต้องต่อได้ตลอดช่วงติดตั้ง |
| เวลา | ประมาณ **25 นาที** (ส่วนใหญ่คือรอดาวน์โหลด ไม่ต้องเฝ้า) |
| อีเมลของตัวเอง | ใช้แจ้ง SEC ตอนดึงงบการเงิน — **ห้ามใช้ร่วมกับเพื่อน** |

## ขั้นที่ 1 — ติดตั้ง Python

1. เข้า https://www.python.org/downloads/
2. กดปุ่มดาวน์โหลด Python รุ่นล่าสุด (ต้อง **3.11 ขึ้นไป**)
3. เปิดไฟล์ที่ดาวน์โหลดมา

> ⚠️ **ขั้นตอนที่พลาดกันบ่อยที่สุด**
> ในหน้าจอแรกของตัวติดตั้ง ให้**ติ๊กช่อง "Add Python to PATH"** ที่อยู่ด้านล่างก่อน
> แล้วค่อยกด Install Now — ถ้าลืมติ๊ก โปรแกรมจะหา Python ไม่เจอ

4. รอจนขึ้น Setup was successful แล้วกด Close

## ขั้นที่ 2 — ดาวน์โหลดโปรแกรม

**วิธีที่ง่ายที่สุด**

1. เปิด https://github.com/three-fastbull/FASTDEEPSCANNER
2. กดปุ่มเขียว **Code** → **Download ZIP**
3. แตกไฟล์ ZIP ไปไว้ที่ที่หาเจอง่าย เช่น `D:\FASTDEEP SCANNER`

> อย่าแตกไฟล์ไว้ในโฟลเดอร์ Downloads หรือ Desktop ที่ซิงก์กับ OneDrive
> เพราะ OneDrive จะพยายามอัปโหลดข้อมูล 600 MB ขึ้นคลาวด์ตลอดเวลา

**ถ้าใช้ Git เป็น** เปิด Command Prompt แล้วพิมพ์

```bash
git clone https://github.com/three-fastbull/FASTDEEPSCANNER.git
```

## ขั้นที่ 3 — ติดตั้งด้วยคำสั่งเดียว

เข้าไปในโฟลเดอร์ที่แตกไฟล์ไว้ แล้ว **ดับเบิลคลิกไฟล์ `setup.bat`**

โปรแกรมจะทำให้อัตโนมัติ 5 ขั้น:

| ขั้น | ทำอะไร | ใช้เวลา |
|---|---|---|
| 1 | หา Python บนเครื่อง | ทันที |
| 2 | ถามอีเมลของคุณ แล้วบันทึกลงไฟล์ `.env` | ทันที |
| 3 | ดึงราคาหุ้น 1,458 ตัว ย้อนหลัง 5 ปี | 2-5 นาที |
| 4 | ดึงงบการเงินจาก SEC EDGAR | ~15 นาที |
| 5 | ตรวจความพร้อมทั้งหมด | ทันที |

**ตอนขั้นที่ 2 จะมีคำถามขึ้นมา** ให้พิมพ์อีเมลของตัวเองแล้วกด Enter

หรือถ้าอยากข้ามการถาม ให้เปิด Command Prompt ในโฟลเดอร์นั้นแล้วพิมพ์

```bash
setup.bat you@example.com
```

เมื่อขึ้นข้อความ **"ติดตั้งเสร็จแล้ว"** แปลว่าพร้อมใช้งาน

## ขั้นที่ 4 — เปิดใช้งาน

ดับเบิลคลิก **`OPEN_FASTDEEP_SCANNER.bat`**

เบราว์เซอร์จะเปิดที่ `http://127.0.0.1:8765` เอง

> ครั้งแรกอาจใช้เวลา 5-10 วินาทีกว่าจะขึ้นครบ เพราะโปรแกรมกำลังอ่านข้อมูลราคา 136 MB
> ครั้งต่อไปจะเร็วขึ้นมาก

**เลข 127.0.0.1 คืออะไร** — คือเครื่องของคุณเอง โปรแกรมนี้ทำงานบนเครื่องคุณล้วน ๆ
ไม่ได้ส่งข้อมูลไปที่ไหน และคนอื่นเปิดลิงก์นี้ไม่ได้

## ปัญหาที่เจอบ่อย

**"ไม่พบ Python 3.11 ขึ้นไปบนเครื่องนี้"**
ตอนติดตั้ง Python ลืมติ๊ก "Add Python to PATH"
→ ติดตั้ง Python ใหม่อีกครั้ง คราวนี้ติ๊กช่องนั้นด้วย หรือเลือก Modify แล้วเปิดใช้ตัวเลือกนั้น

**"ดึงราคาไม่เสร็จภายใน 20 นาที"**
ผู้ให้บริการข้อมูลกำลังจำกัดอัตราชั่วคราว ไม่ใช่ความผิดของคุณ
→ รอ 10-15 นาที แล้วรัน `setup.bat` ใหม่ ระบบจะทำต่อจากเดิม ไม่ต้องเริ่มใหม่หมด
→ **ถ้าทั้งห้องติดตั้งพร้อมกันจะยิ่งช้า** ควรทยอยกันคนละเวลา

**ดึงงบการเงินแล้วขึ้น 403**
อีเมลใน `.env` ใช้ไม่ได้จริง หรือใช้ซ้ำกับเพื่อนหลายคน
→ เปิดไฟล์ `.env` ด้วย Notepad แก้บรรทัด `FASTDEEP_SEC_CONTACT=` ให้เป็นอีเมลจริงของตัวเอง

**หน้าเว็บขึ้น "Scan error"**
เซิร์ฟเวอร์ปิดไปแล้ว
→ ปิดหน้าต่างเบราว์เซอร์ แล้วดับเบิลคลิก `OPEN_FASTDEEP_SCANNER.bat` ใหม่

**เปิดแล้วค้างที่ loading นาน**
ครั้งแรกหลังอัปเดตข้อมูลต้องอ่านไฟล์ 136 MB ก่อน
→ รอ 10 วินาที ถ้าเกิน 1 นาทีให้รัน `doctor` ดูว่าข้อมูลครบไหม

**Windows ขึ้นเตือนว่า "Windows protected your PC"**
เป็นการเตือนปกติของไฟล์ที่ดาวน์โหลดมาใหม่
→ กด **More info** → **Run anyway**
